# tamesu Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Build tamesu, an agentic testing framework and CLI in Go that runs YAML or Go tests against web apps (browser), REST agents, LiveKit voice agents and SIP phone agents, phase by phase as `docs/design.md` prescribes.

**Architecture:** A multi-module Go monorepo modelled on xavidop/tobira: a light root module (`github.com/xavidop/tamesu`) with the public API, config loading, secrets (mamori), redaction and the cobra CLI package; heavy dependency sets (Genkit in `llm/`, LiveKit/pion in `targets/livekit` and `targets/sip`, chromedp in `targets/browser`, CGO audio in `audio/`) each in their own `go.mod`; `cmd/tamesu` is the only module that links everything. All AI goes through Genkit in `llm/`; all secrets go through mamori.

**Tech Stack:** Go 1.27, cobra, yaml.v3, invopop/jsonschema, mamori v1.13.0 (+ provider modules in `cmd/tamesu` only), bmatcuk/doublestar, testify; Genkit Go v1.14 (`llm/`); LiveKit server-sdk-go v2; chromedp; ojg (JSONPath); Astro 7 docs site; golangci-lint v2, GoReleaser v2, semantic-release.

**Spec:** `docs/design.md` (copied from the original SPEC.md). Sections are referenced as §N below.

## Global Constraints

- Go `1.27` in every `go.mod`; `golangci-lint` clean (`.golangci.yml`, standard set); `gofmt -l .` empty.
- Module path `github.com/xavidop/tamesu`; CLI module `github.com/xavidop/tamesu/cmd/tamesu` with `replace github.com/xavidop/tamesu => ../..` (and one `replace` per sibling module it imports). Every module builds and tests with `GOWORK=off`.
- Root module never requires Genkit, LiveKit, pion, chromedp, onnxruntime, opus or any cloud SDK (`.github/scripts/check_root_deps.sh`). No module but `llm/` (and `llm/plugins/*`) imports a model provider SDK (`check_ai_deps.sh`).
- All secrets through mamori: declared under `secrets:` as refs, resolved once per run, held as `secret.String`, revealed only at use. `${VAR}` is for non-secret values. Values resolved through mamori are registered with `internal/redact` and rendered as `‹secret:NAME›` everywhere.
- Exit codes (§3): 0 passed, 1 test failures, 2 config/schema error (also usage errors), 3 infrastructure error, 4 budget exceeded.
- Conventional Commits on every commit (`feat:`, `fix:`, `docs:`, `chore:`, `refactor:`, `test:`, `ci:` with scopes like `feat(livekit):`).
- User-facing errors carry the suite file, test name and YAML line (`file.yaml:12: tests[1] "refund": ...`).
- `context.Context` first on every blocking call; `log/slog` for all logging; `-v` enables debug.
- Public API surface: `tamesu`, `target`, `targets/*`, `assert`, `metrics`, `llm` only. Everything else under `internal/`.
- Brand: 試す tamesu; tagline *Put your web apps and AI agents to the test.*; colours indigo `#1E2A5A`, vermilion `#E5482F`, off-white `#F7F3EA`; MIT © Xavier Portilla Edo.
- README, `site/src/pages/docs/`, `skills/tamesu/SKILL.md` updated with every phase; claim-check scripts keep README and docs honest: a command, flag or target may be named only if the CLI has it, or on a line (or in a section) that says "planned".

## Review Focus

1. **A suite that references a secret nobody declared** (`{{secrets.X}}` with no `secrets.X` in suite or project): `tamesu validate` must report `file:line: secret X is not declared`, not fail at run time. Test in Task 4.
2. **`${VAR}` unset while validating on a machine without that variable** (CI validating suites that need `LIVEKIT_URL`): `validate` warns and keeps the placeholder; only `run`/`doctor` treat it as a config error. Test in Task 4.
3. **A YAML file that is valid YAML but not a suite** (a plain `tamesu.yaml` matched by a `**/*.yaml` glob, or a Kubernetes manifest): `validate` reports `file:1: not a tamesu suite (no "suite:" key)` and exit 2, never a Go panic or a decode dump. Test in Task 4.
4. **A secret shorter than three bytes** (`PIN=1`): redaction must not rewrite every digit in a transcript; the redactor skips values under 3 bytes and `doctor` warns. Test in Task 6.
5. **`tamesu init` in a directory that already has a `tamesu.yaml`**: refuses with exit 2 and names the file, unless `--force`. Test in Task 8.

### Task 41: WebSocket streaming in `targets/rest`

### Task 42: `targets/realtime` — the OpenAI Realtime protocol
- [x] Target type `realtime`: `url` (default `wss://api.openai.com/v1/realtime`), `model` (`?model=`), `headers` (`Authorization: Bearer {{secrets.OPENAI_API_KEY}}`), `session` (a map merged into `session.update`: instructions, tools, voice, output modalities), `mode` text|audio, `done_tool` (a function call with this name ends the session; default `end_session`), `turn_timeout` (default 60 s).
